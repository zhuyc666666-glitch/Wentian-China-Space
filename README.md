# 问天 WENTIAN - 中国航天沉浸式数字探索平台

Wentian-China-Space is an immersive digital platform themed around China's space exploration.

This project is designed for a web design / front-end development competition. It is not a traditional information website; it combines Web 3D, scroll-driven storytelling, data visualization, AI interaction, and gamified mission experiences into one exploratory China spaceflight experience.

## Project Positioning

- Web 3D space scenes and interactive mission environments
- Scroll narrative for milestone-driven storytelling
- Data visualization for spaceflight systems, missions, and achievements
- AI interaction for guided exploration and Q&A
- Gamified tasks that turn browsing into a mission-based journey

## Status

Project initialized. Feature development has not started yet.
